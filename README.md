## 🚀 Antes de começar

Antes de executar o projeto, instale as dependências do front-end e do back-end.

### Front-end

```bash
npm install
```

### Back-end (.NET)

```bash
dotnet restore
```

### Executando o projeto

Front-end:

```bash
npm run dev
```

Back-end:

```bash
dotnet run
```

> **Importante:** Não se esqueça de instalar todas as dependências antes de executar o projeto.
